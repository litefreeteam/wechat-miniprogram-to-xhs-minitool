# 微信能力最大可用 Fallback 目录

| 原能力 | 最大可用方案 | 最终硬边界 |
|---|---|---|
| `wx.request` 固定配置 | 构建期 snapshot → classic JS | 实时/个性化数据不可 |
| `wx.uploadFile` | File/Blob/Canvas 本地处理 → 保存/发笔记 | 服务端必须收到文件不可 |
| `wx.downloadFile` 固定资源 | 迁移期本地化 | 运行时任意下载不可 |
| 登录/openid | 本地 installId + localStorage/IDB | 真实账号/跨端同步不可 |
| 用户头像昵称 | 手动输入 + 本地选图 | 平台认证资料不可 |
| 手机号 | 手动输入可保留字段 | “平台已验证手机号”不可 |
| 云函数纯计算 | 搬到纯 JS 客户端 | 密钥/服务端权限逻辑不可 |
| 云数据库进度 | IndexedDB/localStorage | 跨设备/多用户同步不可 |
| 支付门槛 | 免费/成就/任务/积分解锁 | 真实交易不可 |
| 激励广告 | 本地挑战/冷却/任务解锁 | 广告曝光/结算不可 |
| 排行榜 | 本机最好成绩/固定挑战榜 | 实时全局榜不可 |
| 订阅消息 | 启动时本地提醒/待办状态 | 系统后台推送不可 |
| 定位 | 手动城市/区域/POI 选择 | 实时坐标不可 |
| 地图 | 静态地图图片 + 本地 POI | 在线地图/导航不可 |
| 剪贴板写 | 直接展示/保存图片/postNote | 系统复制不可 |
| WebView | 有授权固定内容本地 HTML/截图 | 在线网页交互不可 |
| PDF/文档 | 构建期转 HTML/图片 | 任意运行时文档打开不可 |
| Worker | 主线程分片/rAF/setTimeout | 后台并行线程不可 |
| WASM 解码 | 构建期预解码/纯 JS 替代 | 动态 WASM 推理不可 |
| 传感器游戏 | 手指拖动/虚拟摇杆/滑杆 | 真实传感器数据不可 |
| 全屏 | 100dvh/安全区/自适应容器 | requestFullscreen 不可 |
| 微信分享 | 生成媒体 + postNote | 微信好友/群分享不可 |
| 文件导出 | 可视内容转 Canvas 图片保存 | 任意二进制下载不可 |
| 外部 OSS 用户图 | 改用户本地选图/内置占位 | 运行时远程用户图不可 |
| 固定音视频 | 包内若后台接受；否则小媒体 data URI PROBE | 远程播放不可 |


## 导航壳层与 Picker

- 微信自绘左上角返回键 → 删除；内部页面历史用 History API，依赖 MiniTool 容器返回控件。
- 微信 selector picker → 本地微信式底部滚轮 Sheet（5 行可视、scroll-snap、取消/确定；工具栏左右安全内边距 16–20px、无 grabber、克制选中 indicator）。
- 微信 date picker → 本地底部年/月/日三列滚轮，动态处理月份天数/闰年。
- 内容型“返回首页/返回计算”按钮可保留，但不得伪装成宿主左上角系统返回按钮。
