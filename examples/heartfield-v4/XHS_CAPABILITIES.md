# 小红书小工具原生能力矩阵（V4.0）

官方文档：https://miniapp-sandbox.xiaohongshu.com/minitool/doc

| 功能 | 使用位置 | 前提/回退 | 意义 |
| --- | --- | --- | --- |
| Storage | 每次行走保存 V4 坐标、步数、进度、历史 | 平台 9.46+；浏览器本地存储；清理缓存可能丢失 | 下次继续脱险 |
| getWindowInfo | 初始化、窗口变化 | 平台 9.49+；CSS safe-area 降级 | 不挡住原生菜单 |
| writeTempFile + saveImageToPhotosAlbum | 情侣战报页 | 原生可用时才显示保存成功；浏览器下载 | 分享成功逃出的截图 |
| postNote | 情侣战报页 | 用户主动点击并确认发布 | 自主发小红书笔记 |
| interactionOpenApi | 挑战码、战报弹窗 | 平台 9.49+；用户确认评论 | 评论区发布相同地图的 PK 入口 |
| getFollowStatus + followAuthor | 首页 | 平台 9.51+；无能力则隐藏 | 可选关注作者 |
| 陀螺仪 | 首页体感按钮，背景轻微视差 | 平台 9.50+；显式开启，离开/关闭停止 | 场景氛围，不改变触控格坐标 |

V4 规则独立于平台，所有小游戏推理和动画在本机执行。照片只读入当前进程内存用于头像渲染，不自动持久化或发送网络。

限制：不接入未开放的 AI、支付、真正多人远程联机，也没有调用外部服务器。

上传小红书前仍需运行上传页当时指定的代码改写/验包流程并在真实 App 内验证，不可把 SDK mock 通过视作审核结果。
