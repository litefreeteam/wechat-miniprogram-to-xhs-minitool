# 心动雷区 · 带 TA 逃出去（V4.0）

**移动端 2.5D 双人接力逃脱扫雷游戏**，在 V3 原型基础上真正重做了胜利条件、移动约束、雷区生成和上手提示。开局就能知道目的：**两个人从左下角绿色起点，一步一步走到右上角金色终点**。

## 立即运行

下载并解压 `heartfield_escape_v4_playable.zip`，将 `index.html`、`style.css`、`game.js`、`xhs-adapter.js` 保持在同一目录，浏览器打开 `index.html` 即可。无需注册、联网、CDN 或后端。

## 不用记扫雷规则也能上手

1. 首次选择「初次约会」（6×6）。两人站在**绿色起点**，右上角是**金色终点**。
2. 先踩已经标出绿色对勾的安全格。一次只能选择人物**上、下、左、右紧邻的一个格子**，不能跳到地图远端。
3. 已知安全格可反复经过；新翻开的数字表示**周围八个方向有多少颗雷**，不是该格有雷。数字 0 会自动打开一片安全区，但角色仍只能一步一步行走。
4. 推理可能有雷时，长按插旗或切换「标记地雷」；旗帜只是你的猜测，不能清雷。雷达仅可扫描下一步相邻格，不移动角色。
5. 出错遇雷后两人留在当前安全格：守护可抵挡一次，或在 5 秒内由搭档连点 5 次 SOS 挽救爱心；否则扣血。3 颗爱心耗尽失败。
6. **走到金色终点立即获胜**，无须找出全部安全格；过程可能触发情侣默契问答。双方一起移动、轮流决定下一步，单人模式同样可玩。

地图隐藏地雷，程序只保障存在一条从起点到终点的安全通路，**不保证每一步都能纯逻辑推出**；玩家可用雷达、守护等道具降低猜测风险。挑战码+难度完全相同会生成相同的雷区和安全通路，但**不提供跨设备实时联机**。

## V4 核心改动

- 从“任意地点翻格、翻完全部安全格通关”改为“共享小队一步移动、抵达目标通关”。
- 确定性关卡生成：以挑战码为种子，先生成一条上下左右连通的无雷路径，再在路径外分配雷，保留传统扫雷 8 邻格数字计算。
- 出发区、终点、当前相邻可行走格高亮；第一步预先揭示安全格，开局不靠盲猜。
- 两名角色跟随同一位置移动，轮流作出探索/插旗/侦查的决策；踩雷或护盾动作不会传送角色。
- 根据距离终点的进度显示主线剧情，弹窗与战报描述改为“成功逃出”。
- V4 存档包含当前位置、移动步数、轨迹以及雷达侦查记录，并重新生成地雷地图做安全校验；V3 存档隔离，避免因目标规则变化读错旧局。
- 小屏幕的固定操作栏高度进一步缩减；保持原有场景、真人头像本机处理、主题剧情、默契问答、挑战海报等。

## 小红书小工具能力（沿用 V3）

平台注入 `window.xhs.miniTool` 时，根据客户端版本及 API 可用性选择接入原生 Storage、getWindowInfo、安全区避让、writeTempFile、saveImageToPhotosAlbum、postNote、interactionOpenApi 评论区同题 PK、followAuthor 和可选陀螺仪视差。普通浏览器自动隐藏不可用入口。没有接入尚未开放的 AI、网络/WebSocket、精确定位或在线房间。真人照片不持久化、不上传；手动分享到笔记前应征得对方同意。

平台文档：https://miniapp-sandbox.xiaohongshu.com/minitool/doc

注意：这是**可运行 H5 开发包**，尚未经过小红书上传页实时的官方改写口令、App 真机与审核确认，不能声称发布合规完成。

## 代码结构

| 文件 | 用途 |
| --- | --- |
| `index.html` | 入口界面、目标指引和操作区 |
| `style.css` | 主题、移动端与安全区 |
| `game.js` | 地雷、路径、移动、2.5D、情侣事件、胜负和存档 |

| `test_regression.py` | `test_escape.py` 的兼容入口 |
