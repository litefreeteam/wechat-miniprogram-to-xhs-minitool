# 心动雷区 Heartfield v3.0 · 小红书小工具增强版

离线 2.5D 情侣接力扫雷游戏。无需注册、服务器、AI 或外部 CDN。保留 6×6 / 7×7 / 8×8 三档难度、三种动态场景、卡通角色+真人头像、雷达/守护、踩雷 SOS、情侣默契问答以及挑战码复现地图。

## 本次更新（2026-10-23）

- **评论区同题 PK（9.49+）**：在「分享挑战码」或「生成情侣战报」里主动点击「评论区 PK」，离线生成 3:4 战报并经 `writeTempFile` 转为临时路径，再由 `interactionOpenApi` 携带图片和评论草稿打开评论区。`miniToolSnapshotInfo` 包含 `{ v, page, code, level, scene, mode }`，长度远小于 2 KB。仅 `routed === true` 反馈已进入评论流程；**不宣称评论实际发布成功**。普通浏览器隐藏入口。
- **笔记与相册增强**：优先 `writeTempFile` + `postNote` 或 `saveImageToPhotosAlbum`，失败时媒体允许按文档回退 `data:` 图片。发布流程由用户最终确认，不能代表审核通过。
- **本机存档续局（9.46+）**：优先平台 Storage API，低版本/普通浏览器使用带异常处理的 `localStorage` 降级；每步保存、结算后清理，支持首页「继续上次冒险」。存档通过 `schema:3` / 难度 / 码值 / 地块形状校验；重建地雷布局而非信任外来地雷数据。真实头像不会写入存档，避免在持久缓存中保留人像数据。
- **本机情侣战绩（9.46+）**：最近 12 场的关卡、结果、得分、默契值、挑战码、用时。仅保存到当前小工具设备，不联网也不跨设备同步；卸载、清理数据可能丢失。
- **原生安全区（9.49+）**：通过 `getWindowInfo` 获取窗口安全区与可见原生按钮矩形，调整顶部避让与底部操作栏，失败则保留原 CSS。不会把 `screenTop` 错当成容器内偏移。
- **可选背景体感（9.50+）**：用户主动开启，`startGyroscope`/`onGyroscopeChange` 感知角速度并仅对场景装饰层产生轻微视差，棋盘坐标和点选区域不变。关闭/切后台停止采集、解除监听。不把角速度误称为绝对倾角。
- **关注作者（9.51+）**：延续 `getFollowStatus` / `followAuthor`，补充返回前台刷新，按已关注、作者本人、取消及频控处理。
- **AI / 精确定位 / 实时联机**：未接入。游戏没有这些真实需求；尤其跨设备实时同步受沙箱禁止网络请求/WebSocket 限制。

## 直接运行

解压 `heartfield_v3_playable.zip`，确保 `index.html`、`style.css`、`game.js`、`xhs-adapter.js` 在同一目录。浏览器打开 `index.html` 即可玩；普通浏览器中没有原生按钮，使用浏览器本地存储。

## 源码与测试

- `index.html`：页面结构与游戏入口
- `style.css`：响应式视觉与平台安全区
- `game.js`：扫雷规则、2.5D 渲染、角色、情侣剧情、续局和战绩
- `xhs-adapter.js`：平台能力隔离层、版本判断和降级
- `test_regression.py`：10 项核心功能回归（需 Playwright + Chromium）
- `test_platform.py`：小红书 SDK 模拟交互和浏览器降级验证

测试：`python test_regression.py && python test_platform.py`。已用本地 Chromium 和模拟 SDK 测试；**尚未验证 iOS / Android 真机小红书容器与审核结果**。

## 隐私与限制

真人头像只在内存中读取裁切，没有外传、不会自动写入本机历史、不会自动分享；如果用户主动发布包含人像的战报，请先征得对方同意。Storage 属于本地易失缓存，不提供永久保存保证。挑战码是同地图种子，不是实时游戏房间。
